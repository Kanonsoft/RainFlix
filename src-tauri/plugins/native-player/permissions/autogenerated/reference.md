## Default Permission

RainFlix Android playback and player event subscriptions.

#### This default permission set includes the following:

- `allow-start`
- `allow-stop`
- `allow-set-source`
- `allow-update-episodes`
- `allow-update-streams`
- `allow-update-subtitles`
- `allow-load-subtitle`
- `allow-register-listener`
- `allow-remove-listener`
- `allow-take-install-link`
- `allow-set-orientation`
- `allow-update-preload`
