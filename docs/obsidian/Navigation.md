# Navigation

Below 1024px, a fixed bottom icon bar replaces the hamburger and side drawer. Home, Anime, Browse and My List remain available; native apps add Settings, while web adds Downloads. Add-ons is accessed inside Settings instead of navigation. Search stays in the top header. The bar follows the current route, respects safe-area insets, reserves content/footer space and hides during playback. Desktop retains the horizontal top navigation. The bar is inside the inert app shell, not a portal over the native/browser player. Settings stays selected on the Add-ons and subtitle settings pages.

Pages do not display routing Back buttons, including More like this. Browser/device Back and remote Back commands remain supported. Browser history is used when a RainFlix history entry exists; remote/device direct-link fallback returns to Home, Downloads to the web landing page, and More like this to its title. Android's system Back first closes the visible drawer/player or current stream-selection step, then uses this route history. Native player Back and episode/provider selection Back controls remain available; they are playback controls, not page-routing buttons.

Title selection steps use `selection=episodes|streams` and an opaque provider ID in the URL. Back traverses streams, episodes, then providers without leaving the title unexpectedly. Series use provider -> episodes -> streams; in-player selection keeps episodes -> provider -> streams. Episode selection updates the previous episode step before pushing streams, retaining the selected episode on Back. Automatic playback handoffs replace transient entries. Query-only title transitions preserve page scroll and keep the mobile layout footprint stable; only the inner source list resets. Catalog filter state lives in its URL. Scroll positions are held in a bounded in-memory map and restored on page-history Back; restoration briefly observes layout while lazy content returns, and stops on user scrolling. Positions are not persisted across sessions.

Browse omits result counts. Anime paged grids reserve empty slots on shorter pages so rows and columns keep their dimensions. UI text is non-selectable, while inputs and editable fields retain text selection. Hover styling is restricted to hover-capable pointers, not touch devices.

Title-page stream and episode lists remain bounded scroll areas, but use automatic vertical scroll chaining. Reaching either edge passes wheel/touch scrolling back to the title page instead of trapping it with overscroll containment. This shared React layout applies to web, Windows and Android; native fullscreen playback panels retain their independent behavior.

Newest movie/series sections link to `/newest/movie` and `/newest/tv`, preserving any genre/year filter. These dedicated catalogs load later TMDb pages on scroll with ghost cards and retry on failure. The sort and released-only constraints match the Home newest rows. Add-on browse pages likewise append `skip` batches on scroll, stopping when the provider returns no new titles, including providers ignoring skip. No page buttons are rendered.
