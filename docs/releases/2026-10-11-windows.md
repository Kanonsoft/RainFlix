# RainFlix Windows - Playback and Settings Preview

Private testing release. Windows x64 installer; no automatic publishing.

## New

- Native Settings for motion, preferred subtitle/audio languages, intro/outro skipping, next-episode prefetch, preview and automatic next.
- English subtitle preference and source-default audio. Reduced motion remains off by default on Windows.
- Weekly startup artwork cache with bundled TMDb posters for first launch and offline fallback.
- Cache clearing preserves installed add-ons, My List, history and settings.
- Improved stream/provider selection with add-on logos, quality indicators, dividers and full release descriptions.
- Refined player controls and language-grouped subtitles.
- Slightly lighter dark background; optional static ambient background and simple hero fades.
- Web My List shows saved titles only; native apps retain history views. Web download action now uses Download + R branding.

## Notes

Torrent playback and prefetch still depend on available peers and matching sources. Skip behavior depends on available markers and player capabilities. This installer does not publish a GitHub release or change another application's protocol defaults.
