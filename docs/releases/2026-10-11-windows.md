# RainFlix 1.0.0 for Windows

A more focused RainFlix experience with native playback, streamlined discovery,
and a calmer reduced-animation theme.

## Highlights

- Browse replaces the separate Movies, Series, Genre, and Year header links, with combined catalog filters and infinite scrolling.
- Search focuses on the query and results, including actors and productions.
- Native stream playback uses the RainFlix player with bundled mpv and app-owned torrent support.
- Playback includes pause, circular seek/volume sliders, speed, audio tracks, language-grouped subtitles, and five-second seek buttons.
- Episode navigation, next/previous, optional intro/outro skipping, automatic next, next-episode preview, and matching-source prefetch.
- Persistent add-ons and My List, plus Continue Watching and Watched with context-menu actions.
- Add-on directory and installed tabs share detailed cards; installation keeps the current tab.
- Official services and available add-on providers share the Streams list, with provider logos and readable source details.
- One consolidated add-on no-streams message instead of repeated provider failures.
- Starts maximized; fullscreen preference changes apply immediately, with Escape returning to windowed mode.
- Reduced animations uses a fixed charcoal-gray background without movie artwork.
- Smoother decoded-image background/hero transitions and R artwork during startup.

## Installation

Download and run `RainFlix_1.0.0_x64-setup.exe`. This is the Windows x64
installer; WebView2 may require an internet connection if not already installed.
For updates, keep the existing app data rather than uninstalling or clearing it.

## Notes

Streams, torrent peers, subtitle availability, and next-episode warmup depend
on external providers. Prefetch is best-effort, not guaranteed instant playback.
Casting is not included. Use only media you are authorized to access.

The shared interface passed 132 browser tests, and the installer built
successfully. Browser coverage is not a substitute for installed Windows
playback verification. This release does not enable automatic app updates.
