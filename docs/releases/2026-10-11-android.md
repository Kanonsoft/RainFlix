# RainFlix Android - Playback and Settings Preview

Private testing release. ARM64 APK; no store publication.

## New

- Native Settings with reduced motion enabled by default, English subtitles, source-default audio and safe artwork cache clearing.
- Weekly startup poster cache with bundled posters for the first offline launch.
- One animated horizontal buffering indicator with measured progress once media is available.
- Intro/outro skip options, adjustable timing fallbacks, automatic next, next-episode preview and same-provider torrent prefetch.
- Transparent touch controls, cumulative double-tap seeking, grouped subtitle/audio languages and subtitle appearance controls.
- Improved episode, provider and source drawers with add-on logos and readable release details.
- Lighter dark background and updated web download branding.

## Notes

Prefetch depends on peers and source availability; it cannot guarantee immediate playback. Timing-based skipping is approximate and off by default. Codec support depends on the device. Settings and installed add-ons remain device-local.

Use the debug update APK over the existing debug-signed phone installation to preserve app data. The signed release APK uses a different key and cannot update a debug installation directly. Native playback changes are provided for manual device testing; no phone installation was performed for this release.
