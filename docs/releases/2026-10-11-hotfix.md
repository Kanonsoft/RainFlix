# RainFlix Android and Windows Hotfix

- Fixed the Android release-only startup crash caused by missing R8 enum reflection rules.
- Cached installed add-on logos for seven days, including cached PNG artwork for native stream drawers.
- Reduced motion now uses a solid dark background instead of a title thumbnail.
- Removed history ellipsis buttons; use right-click or a 600 ms touch hold. Browser context menus are disabled.
- Native apps no longer show Torrent Playback mode selection; torrents use RainFlix's native player.
- Source badges show reported peers alongside quality, codec and size when the add-on provides a count.
- Series title pages now select a stream provider first, then an episode, then the provider's source options. Continue Watching still resumes the remembered source.
- Web navigation uses a violet Downloads text button. RainFlix appears in the web Streams list and links to app downloads.
- Replaced Movies, Series, Genres and Year navigation with Browse. Browse keeps catalog filters; Search has only its query bar and results.
- Refined the Add-ons directory and installed cards, removed directory attribution, and made valid browser install links install immediately without a second confirmation button.
- Simplified Settings by removing fallback-duration and storage controls; added opt-in Windows fullscreen on start with Escape to leave fullscreen.
- Removed decorative icons from My List section headings.
- Web builds automatically install the configured stream-only Yastream manifest; native apps keep their existing installed-provider choices.

Peer counts are provider-reported availability, not live connected peers. Playback still depends on source availability. Add-on image hosts must allow image retrieval for persistent artwork caching; failures retain existing artwork or use the R fallback.
